================================================================================
UPGRADE PATHS
================================================================================

1. Add Real Models
   $ ./installers/download_models.sh

2. Enable GPU
   Edit config/envy.yaml:
   - n_gpu_layers: 35

3. Upgrade to Power Profile
   Edit config/envy.yaml:
   - profile: power

4. Add Custom Skills
   Create skills/my_skill.py
   Add to enabled_skills in config

5. Remote LLM Fallback
   Edit config/envy.yaml:
   - llm.remote.enabled: true
