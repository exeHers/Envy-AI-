================================================================================
ARCHITECTURE SUMMARY
================================================================================

Microservices:
  1. wake_listener: VOSK-based keyword detection (~5-10% CPU idle)
  2. stt_service: Faster Whisper speech-to-text (streaming capable)
  3. tts_service: pyttsx3/Coqui text-to-speech
  4. llm_adapter: llama.cpp local LLM with free remote fallback
  5. router: Intent classification and request routing
  6. skill_manager: Plugin system for modular capabilities
  7. web_dashboard: FastAPI + modern HTML/JS interface

Skills (Modular Plugins):
  - CodeSkill: Create/edit files via voice
  - ResearchSkill: Generate research summaries
  - SysControlSkill: Execute whitelisted system commands
  - ReminderSkill: Set and manage reminders

Resource Management:
  - Profiles: low (2GB RAM), balanced (4GB), power (8GB)
  - CPU throttling: 40-80% depending on profile
  - GPU offloading: 0-35 layers depending on profile
  - Automatic fallbacks when resources limited

Security:
  - Command whitelisting (default: safe read-only commands)
  - Voice + dashboard confirmation for destructive actions
  - Sandboxed skill execution with timeouts
  - No cloud services by default (all local processing)

================================================================================
HARDWARE OPTIMIZATION
================================================================================

Target Hardware: Intel i3 + GTX 1070 (8GB) + 16GB RAM

Recommended Configuration (in config/envy.yaml):
  profile: balanced
  stt: faster-whisper base model, int8 quantization
  llm: llama-2-7b Q4_K_M quantized (4GB), 35 GPU layers
  tts: pyttsx3 (lightweight)

Expected Performance:
  - CPU: 40-60% average, 4 threads
  - RAM: 2-4GB
  - GPU VRAM: 2-4GB (LLM + STT)
  - Wake detection latency: <300ms
  - Full response latency: 2-6 seconds

Scaling Options:
  - Upgrade to "power" profile for better quality
  - Downgrade to "low" profile for older hardware
  - CPU-only mode available (no GPU required)

================================================================================
FREE/LOCAL MODELS USED
================================================================================

All core functionality operates WITHOUT paid APIs:

1. Wake Word: VOSK (Apache 2.0 license)
   - Model: vosk-model-small-en-us-0.15 (~40MB)
   - Source: alphacephei.com/vosk

2. Speech-to-Text: Faster Whisper (MIT license)
   - Model: OpenAI Whisper base (quantized, ~140MB)
   - Auto-downloaded from Hugging Face

3. Text-to-Speech: pyttsx3 (MPL 2.0 license)
   - Uses system TTS engines (eSpeak-ng on Linux)
   - No external dependencies

4. LLM: llama.cpp (MIT license)
   - Recommended: Llama-2-7B-Chat Q4_K_M (~4GB)
   - Source: Hugging Face (TheBloke quantized models)
   - Optional: Can run without LLM using rule-based fallbacks

Optional Remote Fallback:
  - Disabled by default
  - Can enable Hugging Face Inference API (free tier)
  - Documented as opt-in in config/envy.yaml

KNOWN LIMITATIONS & MITIGATIONS

   Limitation: LLM model is 4GB, requires download
   Mitigation: download_models.sh script provided
   Mitigation: System works without LLM using fallback responses
   Upgrade Path: Use smaller model (1-2GB) or remote API

2. Audio Hardware Required
   Limitation: Requires microphone and speakers
   Mitigation: Works in headless mode via web dashboard
   Mitigation: Manual text input available

3. GPU Optional but Recommended
   Limitation: Target hardware (GTX 1070) improves performance
   Mitigation: CPU-only mode works (slower inference)
   Configuration: Set n_gpu_layers=0 for CPU-only

4. First-Run Setup
   Limitation: Initial model download and setup time
   Mitigation: install_envy.sh automates entire process
   Mitigation: Models cached after first download
