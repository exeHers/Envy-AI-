================================================================================
KNOWN LIMITATIONS & MITIGATIONS
================================================================================

1. Model Quality (Local LLM):
   - Limitation: TinyLlama is a small model (1.1B parameters)
   - Mitigation: Provides rule-based fallback responses
   - Upgrade Path: Larger models available (Llama-2-7B, etc.)
   - Impact: Basic queries work, complex reasoning limited

2. STT Accuracy:
   - Limitation: VOSK accuracy depends on acoustic environment
   - Mitigation: Multiple model sizes available
   - Upgrade Path: Whisper models for better accuracy
   - Impact: Works well in quiet environments

3. Resource Requirements:
   - Limitation: Models require 2.5GB disk space
   - Mitigation: Download script handles this automatically
   - Alternative: Smaller models available (trade-off: accuracy)
   - Impact: Initial download time ~10-30 minutes

4. GPU Support:
   - Limitation: GPU acceleration requires CUDA setup
   - Mitigation: CPU-only mode works out of box
   - Alternative: Use 'low' profile for CPU efficiency
   - Impact: Slower inference without GPU

5. Platform-Specific Audio:
   - Limitation: Audio drivers vary across systems
   - Mitigation: Detailed troubleshooting in docs
   - Alternative: Test audio setup before full deployment
   - Impact: May require driver installation on some systems
