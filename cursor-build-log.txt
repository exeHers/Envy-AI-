RESOURCE & PERFORMANCE NOTES
================================================================================

Target Hardware Compatibility:
- Intel i3: ✓ CPU-only mode tested, balanced profile suitable
- GTX 1070 8GB: ✓ GPU support via CUDA-enabled llama-cpp-python
- 16GB RAM: ✓ Memory limits configured (4GB default in balanced mode)

Model Recommendations:
- Wake word: VOSK small (40MB) - minimal CPU usage
- STT: Faster-Whisper tiny/small (75MB-250MB) - fast inference
- LLM: TinyLlama 1.1B Q4 (670MB) - fits in VRAM, fast responses
- TTS: pyttsx3 (system voices) - no additional download needed

Performance Estimates (Based on Architecture):
- Wake word latency: <100ms (VOSK keyword spotting)
- STT latency: 1-3s (Faster-Whisper small)
- LLM inference: 2-5s local (TinyLlama Q4), <1s fallback
- TTS latency: 1-2s (pyttsx3)
- Memory usage: 2-4GB typical (balanced profile)
- CPU usage (idle): <5% (wake listener only)
- CPU usage (active): 20-60% (during processing)

GPU Acceleration:
- CUDA support via CMAKE_ARGS="-DLLAMA_CUBLAS=on"
- GPU layers configurable in config/envy.yaml
- Recommended: 32 layers on GTX 1070 for TinyLlama
