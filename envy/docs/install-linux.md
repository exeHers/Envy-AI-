# Linux Installation Guide

Target hardware: Intel i3 class CPU, NVIDIA GTX 1070 (8 GB VRAM), 16 GB RAM – Ubuntu 20.04+/Debian 12 recommended.

## 1. Prerequisites

- Python 3.10 or 3.11 (`sudo apt install python3 python3-venv python3-pip`)
- `curl`, `unzip`, `build-essential`, `libportaudio2`
- Audio stack (PulseAudio or PipeWire), microphone input
- Optional: `nvidia-driver-535` or newer plus `nvidia-smi` for GPU metrics

```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip curl unzip build-essential libportaudio2
```

## 2. Clone & Install

```bash
git clone https://github.com/your-org/envy.git
cd envy
./install_envy.sh --local-demo
```

`install_envy.sh` creates `.venv/`, installs dependencies, and downloads the small Vosk model. The transcript of the install lives at `artifacts/install-log.txt`.

To fetch larger models later:

```bash
./scripts/download_models.sh --full   # optional llama.cpp + Vosk
```

## 3. Launching

Local demo (no dashboard):

```bash
./run_envy_local.sh --profile balanced --no-gui
```

Full experience (dashboard at http://localhost:8300):

```bash
./run_envy_local.sh --profile balanced
```

Log in with the default credentials `envy/envy` and update `config/envy.yaml` for production.

## 4. Systemd Service

1. Copy files:

```bash
sudo mkdir -p /opt/envy
sudo cp -r * /opt/envy
sudo cp packaging/systemd/envy.service /etc/systemd/system/envy.service
sudo chown -R envy:envy /opt/envy   # create user `envy` if desired
```

2. Edit `/etc/systemd/system/envy.service` to match your install path (`WorkingDirectory`, `ExecStart`).

3. Enable the service:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now envy
```

View logs with `journalctl -u envy -f`.

## 5. GPU Acceleration (Optional)

- Install NVIDIA driver & CUDA runtime (`sudo apt install nvidia-driver-535`).
- The default balanced profile enables GPU for STT/LLM when available. Override via `config/envy.yaml` (`stt.enable_gpu`, `llm.llama_cpp.gpu_layers`).

## 6. Audio Troubleshooting

- Ensure microphone permissions (PulseAudio: `pavucontrol`, PipeWire: `pw-cli`).
- Verify capture devices with `arecord -l`.
- Adjust `wake_listener.energy_threshold` if wake word is missed.

## 7. Logs & Artifacts

- `artifacts/logs/envy.log` – service logs
- `artifacts/tests/` – automated acceptance output
- `artifacts/perf-report.txt` – generated by `artifacts/perf-report-gen.sh`

## 8. Updating

```bash
git pull
source .venv/bin/activate
pip install -e .
```

Re-run `./scripts/download_models.sh --demo` if models have been removed.
